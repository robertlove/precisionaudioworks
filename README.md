# Precision Audioworks

## Installation

### Clone repository

```shell
git clone git@github.com:robertlove/precisionaudioworks.git
cd precisionaudioworks
```

### Install dependencies

```shell
bundle install
```

## Usage

### Serve site

```shell
bundle exec jekyll serve
```
